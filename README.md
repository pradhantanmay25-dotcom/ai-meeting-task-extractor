# AI Meeting Notes & Task Extractor 📝

A lightweight, premium dark-themed micro-SaaS application designed to help project managers and teams instantly turn chaotic meeting transcripts into clean, structured action items.

## ✨ Features
- **Smart AI Parsing:** Uses the Gemini 2.5 Flash API to accurately extract action items, assignees, and deadlines.
- **Zero-Cutoff Engine:** Configured with a 2048 token boundary payload to prevent text from truncating mid-sentence.
- **Mobile-First Design:** A sleek, fully responsive modern card layout built for smartphone displays.
- **Zero-Maintenance:** 100% vanilla HTML, CSS, and client-side JavaScript. No expensive server hosting costs required.

## 🛠️ How to Run Locally
1. Clone or download this repository.
2. Open `index.html` directly in any web browser.
3. Open the file in a code editor and add your own Google AI Studio API key to the placeholder variable:
   ```javascript
   const API_KEY = "YOUR_GEMINI_API_KEY_HERE";
   ```
